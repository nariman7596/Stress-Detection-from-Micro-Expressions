# Core runtime dependencies, pinned and split by Python version.
#
# MediaPipe is the binding constraint on macOS / Apple Silicon:
#
#   * 0.10.x ships the legacy `mediapipe.solutions.face_mesh` API, requires
#     NumPy < 2, and has NO wheels above CPython 3.12 (cp39-cp312 only).
#   * 1.0.x is a pure-Python wheel (`py3-none-macosx_11_0_arm64`), so it installs
#     on any Python 3, but exposes only the Tasks API `FaceLandmarker`, which
#     downloads its model bundle into models/ on first run.
#
# src/face_mesh.py supports both backends and uses whichever is installed, so
# pip's marker selection below is the only place that needs to know which is which.
# The active backend is logged at startup and shown in the overlay footer.

# --- Python <= 3.12: legacy solutions backend, no model download -----------
numpy==1.26.4; python_version < "3.13"
opencv-python==4.10.0.84; python_version < "3.13"
mediapipe==0.10.21; python_version < "3.13"

# --- Python >= 3.13: Tasks backend -----------------------------------------
numpy==2.3.5; python_version >= "3.13"
opencv-python==4.12.0.88; python_version >= "3.13"
mediapipe==1.0.1; python_version >= "3.13"

# NOTE: SciPy is deliberately absent. The spectral analysis in
# src/optical_flow.py uses numpy.fft; nothing in the project imports scipy.
